# Agent Guidelines

## Authoritative Documents
- Do not modify files in `docs/` outside `docs/codex/`.
- Chinese guidelines: `docs/AGRNTS_CN.md` (do not modify).
- Requirements: `docs/REQUIREMENTS.md`
- Architecture: `docs/ARCHITECTURE.md`
- Detailed design: `docs/DESIGN.md`
- Testing: `docs/TEST.md`
- Place generated documents in `docs/codex/` and source code in `src/`.

## Code and Documentation
- Add comments only when they do not affect runtime behavior.
- Mark new functions with `Generated by Codex` and edited functions with `Modified by Codex`.
- Precede each new or edited function with `Purpose: <brief description>` in a comment.
- Add a brief Chinese comment above every generated line of code.
- Keep the implementation plan up to date in `docs/codex/DESIGN.md`.

## Before Committing
- Recheck compliance with the comment requirements.
- Do not mislabel entire human-written files or functions as Codex-generated.
- Preserve existing copyright, license, and valid attribution notices.
- Check `.gitignore` for missing entries and keep intermediate files out of Git.
- Update `readme.md` with the latest build and usage instructions.

## Testing
- Store the current version's test report in `docs/codex/test-report.md` and remove outdated test content from the previous version.
