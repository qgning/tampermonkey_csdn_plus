## 测试边界及待验收

测试中的 isTrusted、DOM 元素和时钟为模拟值，用于验证策略分支，不证明浏览器跨沙箱访问、真实事件路径或站点部署的所有分支可用。前次浏览器加载超时，本轮未完成真实 Tampermonkey 安装与清 Cookie 后验收，不能宣称线上全部通过。

需在 docs/TEST.md 的普通文章和 VIP 样本中人工验证：刷新后滚动超过两屏、停留、切换标签、复制均不弹登录；点击登录及键盘激活入口可打开登录框，关闭后再次点击仍能打开；网页延迟加载后行为保持。

已知限制：无标签登录图标、超过 1.5 秒的异步手动登录、未来新组件、不可改写的属性和错过 document-start 的情况。短授权窗口内无标记自动调用存在误判可能。未修改浏览器 Cookie、登录状态或远程账号数据。

## 既有问题

一键复制仍可能取得工具栏文字；CSS !important 写法仍无效；文章展开仍无完整性判断。本次仅增加登录弹窗策略，不应将这些旧问题记为已修复。
